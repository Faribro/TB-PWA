TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

If test fails with "Record NOT found":

1. Check RLS policy:
   - Run scripts/fix-rls-policy.sql in Supabase SQL Editor
   - Verify policy shows: roles: {service_role}

2. Check server logs:
   - Look for "[webhook] ❌ Failed after retries" messages
   - Check for column name errors

3. Verify environment variables:
   - NEXT_PUBLIC_SUPABASE_URL
   - SUPABASE_SERVICE_ROLE_KEY (not anon key!)
   - KOBO_WEBHOOK_SECRET

4. Check Supabase table schema:
   - Verify column names match koboMapper output
   - Common mismatches: state vs screening_state
